# 성경 검색 웹앱 — 개역개정 · NIV · KJV

세 가지 역본을 나란히 읽고 단어·구절을 검색하는 정적(static) 웹앱입니다.
빌드 도구나 npm 설치가 필요 없고, `index.html`을 열기만 하면 동작합니다.

- 소스 데이터: `ENG-KJV-text/KJV.csv`, `ENG-NIV-test/*.txt`, `KOR-개역개정-text/*.txt`
- 데이터 구조 참고: `mdbible-main` (ESV 데이터는 라이선스 문제로 **사용하지 않음**)

## 2. 기능

### 읽기
- 66권 · 1,189장 전체를 창세기 → 요한계시록 순서로 읽기
- 상단 역본 칩으로 **1개만** 또는 **2~3개 동시 선택** → 자동으로 단/다열 비교 레이아웃
- 책 / 장 / 절 콤보박스로 바로 이동 (장·절 숫자는 실제 데이터에서 계산된 값)
- ◀ ▶ 로 장 이동, `←` `→` 키로도 이동
- 현재 위치와 역본 선택은 `localStorage`에 저장되어 다음 방문 시 복원

### 검색 (상단 "검색" 버튼, 모바일은 우하단 🔍 버튼)
1. **단어 검색**
   - 입력칸 2개 + `AND`(모두 포함) / `OR`(하나라도 포함) 선택
   - 대소문자 무시, 공백 정규화, 구절 일부 문장 검색 가능
   - 검색 대상 역본을 체크박스로 선택 (기본값 = 현재 읽는 역본)
   - 결과는 책·장·절 순으로 정렬, 일치 단어 하이라이트
   - 200개 단위 "더 보기"
   - 결과 줄에서 **구절 제목**을 누르면 미리보기(읽던 위치 유지), **↗**는 그 구절로 이동, **⧉**는 복사
2. **성경 · 장 · 절 찾기**
   - 책 / 장 / 절 콤보박스 + **미리보기** → 읽던 위치를 그대로 둔 채 패널 안에서만 본문 확인
   - **이동** → 해당 절로 실제 이동하며 잠깐 강조 표시

### 읽던 위치를 지키며 미리보기
- 성경 장·절 찾기에서 **미리보기**를 누르면 패널 아래쪽에 본문 카드가 나타납니다.
  읽기 화면(책·장·절, 스크롤 위치)은 전혀 움직이지 않습니다.
- 카드 안에서 **◀ ▶** 로 앞뒤 장을 넘겨 볼 수 있고, 찾은 절은 강조 표시됩니다.
- 검색 결과의 **구절 제목**을 눌러도 같은 카드로 미리 볼 수 있습니다.
- 카드의 **이 위치에서 읽기**를 누르면 그 구절로 이동하며, 상단에 **↩ 읽던 곳** 버튼이 생깁니다.
- **↩ 읽던 곳**을 누르면 이동 직전의 책·장·절과 스크롤 위치로 정확히 돌아갑니다.
- 미리보기는 읽기 상태를 건드리지 않으므로, 카드만 **✕** 로 닫으면 원래 읽던 자리 그대로입니다.

### 복사
- 모든 본문·검색 결과는 드래그 선택 복사 가능 (`user-select: text`)
- 절 단위 ⧉ 버튼, 장 전체 복사, 검색 결과 전체 복사 버튼 제공
- 복사 텍스트에는 `[개역개정] 창세기 1:1 ...` 형태로 역본명과 참조가 포함됨

### 모바일 대응
- 760px 이하: 세로 1단 레이아웃, 역본명 라벨 표시, 절별 복사 버튼 상시 노출
- 검색 패널이 **전체 화면**으로 올라오며, 우상단 **✕ (44×44px)** 로 닫으면
  뒤에 있던 읽기 화면이 그대로 복원됩니다
- 배경 스크림 탭, `Esc`, 브라우저 뒤로가기로도 닫힘
- 본문 스크롤 잠금은 패널이 열린 동안만 적용

### 기타
- 다크 모드 (◐ 버튼, 시스템 설정 자동 감지)
- `/` 키로 검색 열기
- 인쇄 시 UI를 숨기고 본문만 출력


## 4. 데이터 재생성

소스 txt/CSV를 고쳤거나 파서를 바꿨을 때:

```powershell
python "C:\ZZ-Nathan Work\AI\AI-Ring\Bible\bible-webapp\build\build_data.py"
```

- Python 3.9+ 만 있으면 됩니다 (외부 패키지 없음).
- 스크립트 상단의 `ROOT` 경로가 소스 폴더 위치를 가리킵니다.
- 실행하면 `data/*.js` 와 `build-report.txt`가 다시 생성됩니다.

### 누락된 절 채워 넣기 (`build/patches.txt`)

원본에 없는 절은 `build/patches.txt`에 적어 두면 빌드할 때 데이터에 합쳐집니다.
NIV 97절 누락분은 **모두 보충 완료**된 상태이며, 파일에는 그 본문이 들어 있습니다.

```
# 형식:  역본 | 책 | 장:절 | 본문
NIV | Genesis | 50:26 | So Joseph died at the age of a hundred and ten...
KOR | 사도행전 | 24:7 | NONE      ← 이 역본에는 이 절이 없음
```

- 역본: `KOR` / `NIV` / `KJV`
- 책: 번호(1~66), 영어명(`Genesis`), 한글명(`창세기`) 모두 가능
- 본문이 비어 있거나 `TODO`로 시작하면 "대기"로만 집계하고 적용하지 않습니다
- 본문 자리에 `NONE`(또는 `없음`)을 쓰면 **"이 역본에는 이 절이 없음"** 으로 처리됩니다
  (검색·복사에서 제외, 화면에는 흐린 안내 문구만 표시)
- `장:절-끝절` 형식은 절 범위 병합을 해제합니다 (아래 참고)
- 수정 후 `python build\build_data.py` 실행 → `build-report.txt`에
  `적용 N건 / 대기 N건 / 오류 N건`이 표시됩니다

절 범위 병합을 개별 절로 나누려면 (예: 개역개정 시 92:1–3):
```
KOR | 시편 | 92:1-3 | (병합 해제용; 본문은 각 절에 따로 입력)
KOR | 시편 | 92:1 | 1절 본문
KOR | 시편 | 92:2 | 2절 본문
KOR | 시편 | 92:3 | 3절 본문
```
`sp`(병합) 표시가 자동으로 해제되고, 장/절 콤보박스 숫자도 다시 계산됩니다.


### 파서가 처리하는 소스별 특이사항
| 역본 | 형식 | 처리 |
|---|---|---|
| KJV | `KJV.csv` (Verse Index, Book Number, Chapter, Verse, Text) | 정본 절 번호 기준(31,102절)으로 사용 |
| NIV | 권별 `.txt` (UTF-8 BOM), `1:1 본문` | 줄바꿈으로 잘린 이어짐 줄 병합, `40:5+` 병합 표기 처리, 잡음 헤더(`1KI`) 제거, 1역대 장 번호 오류 보정 |
| 개역개정 | 권별 `.txt` (CP949), `창1:1 본문` | `<소제목>` 분리 저장, `시92:1-3` 같은 절 범위 병합 처리, 절 번호 없는 줄은 직전 절에 이어붙임 |

## 5. 데이터 구조

`window.MD_BIBLE` 전역 객체 하나에 모두 담깁니다.

```js
// data/meta.js
window.MD_BIBLE.meta = {
  translations: [{ id: 'kor', label: '개역개정', short: 'KOR', lang: 'ko' }, ...],
  books: [{
    i: 1, en: 'Genesis', ko: '창세기', ab: { kjv: 'Ge', kor: '창' },
    ch: 50,                                  // 장 수
    v: { kjv: [31,25,...], niv: [...], kor: [...] },  // 장별 최대 절 번호
    c: { kjv: [31,25,...], niv: [...], kor: [...] }   // 장별 실제 절 수
  }, ...]
};

// data/kor.js  (niv.js, kjv.js 동일)
window.MD_BIBLE.kor = {
  id: 'kor',
  b: [{
    i: 1,
    ch: [ ['태초에...', '땅이...', ...], [...] ],   // 장 → 절 배열 (null 패딩)
    sp: { '92': { '1': 3 } },                    // 1~3절이 1절로 병합됨
    hd: { '1': { '1': '천지 창조' } },           // 절 위치별 소제목
    na: { '17': [21] }                           // 17장 21절은 이 역본에 없음
  }, ...]
};
```

- `ch[c-1][v-1]` 이 `null`이면 데이터가 아직 없음 → 읽기 화면에 `—` 표시
- `na`(not available)에 들어 있는 절은 **원본 완역본이 "없음"으로 확정한 절**입니다.
  화면에는 `이 역본에는 이 절이 없음`으로 흐리게 표시되고, 검색·복사에서 제외됩니다.
- 절 범위 병합(`sp`)에 속한 절은 "1–3절에 포함"으로 표시
- 역본 데이터는 첫 사용 시 `<script>` 동적으로 삽입해 지연 로드 (KOR 4.5MB / NIV 3.7MB / KJV 4.1MB)
- 검색 인덱스는 역본별 최초 검색 시 1회 생성 후 메모리 캐시 (31k 절 선형 스캔, 체감 지연 없음)

## 6. 알려진 원본 데이터 결함

`build-report.txt`에 전체 목록이 있습니다. 앱은 데이터가 없는 절을 `—`로,
완역본이 "없음"으로 확정한 절을 `이 역본에는 이 절이 없음`으로 표시합니다.
누락분은 `build/patches.txt`로 채울 수 있습니다.

**NIV — 실제 누락 97절 (유일하게 본문을 채워야 하는 역본)**
- 65권에서 **각 권의 마지막 절**이 원본 파일에서 잘려 있음
  (1역대만 예외 — 장 번호 보정 과정에서 마지막 절이 살아남음)
  → 창 50:26 … 계 22:21, 65절
- 1역대 21장 전체 누락 (원본에 해당 장이 없음) → 30절
- 에스겔 23:48–49 누락 → 2절
- 1역대 21~28장의 장 번호가 실제로는 22~29장 → 빌드 시 +1 보정, 중복된 29장 제거
- 본문비평상 실제로 없는 15절은 원본에 절 번호만 있고 본문이 비어 있어
  자동으로 `na`(없음) 처리됨
  (마 17:21, 23:14 / 막 7:16, 9:44, 9:46, 11:26, 15:28 / 눅 17:36, 23:17 /
   요 5:4 / 행 8:37, 15:34, 24:7, 28:29 / 롬 16:24)
- 결과: 31,087절 + 없음 15절 = **31,102절** (KJV와 동일, 97절 보충 완료)
- 보충 본문은 `build/patches.txt`에 있으며, 재빌드해도 그대로 유지됩니다.

**개역개정 — 실제 누락 없음 (번호 체계 차이)**
- 원본은 11곳·13절이 절 범위로 병합되어 있었으나(예: 시 92:1–3 → 1절),
  그중 **9곳 20절을 인쇄 완역본(개역개정)과 동일하게 분할**해 `patches.txt`에 반영했습니다.
  (신 6:18–19, 15:4–5, 30:9–10 / 대상 16:12–13 / 시 92:1–3, 105:5–6 /
   렘 32:3–5, 33:10–11 / 겔 24:4–5)
- 남은 병합 2곳은 **인쇄본도 병합 상태 그대로**여서 나누지 않았습니다.
  (행 15:25–26, 롬 9:1–2 → 화면에 "25–26절에 포함", "1–2절에 포함"으로 표시)
- 완역본이 `(없음)`으로 확정한 13절 + 사도행전 24:7(원본 `(6하반-8상반 없음)`)
  → `na`로 처리, 검색·복사에서 제외
  (마 17:21, 18:11, 23:14 / 막 9:44, 9:46, 11:26, 15:28 / 눅 17:36, 23:17 /
   행 8:37, 15:34, 24:7, 28:29 / 롬 16:24)
- 고후 13:14, 요삼 1:15: KJV와 절 번호 체계가 다를 뿐 본문은 존재
  (개역개정 고후 13:13 = KJV 13:14, 요삼 1:15 = KJV 1:14)
- 요한삼서가 15절 (KJV 기준 14절)
- 결과: 31,086절 + 없음 14절 + 병합 포함 2절 = **31,102절**

**KJV**
- 결함 없음. 31,102절 / 66권 / 1,189장 → 절 번호 정본으로 사용
